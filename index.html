옷·배경 이미지 고르기

영상마다 후보 2장 중 하나를 눌러 고르세요. 안 고르면 왼쪽(1번) 이미지로 만들어요. 둘 다 별로면 다시 만들기를 누르세요 (1~3분 뒤 새 후보가 나와요, 장당 약 60원).

GitHub 연결

쇼츠 제작소에 넣은 것과 같은 GitHub 토큰(github_pat_…)을 넣어 주세요. 이 기기 브라우저에만 저장돼요. 핸드폰에서도 한 번 넣어 주면 돼요.

자동 업로드 멈추기

멈추면 내일부터 영상을 만들지도, 올리지도 않아요. 이미 예약된 글은 업리카에서 지워야 해요.

Kling 유닛 가격

충전할 때 낸 금액 ÷ 받은 유닛 수를 넣어 주세요 (예: 1,000유닛을 140,000원에 샀다면 140). '오늘' 탭의 사용 금액 계산에 써요.
